# The Readograph phone app

The app lives in `mobile/`, an npm workspace next to the website. It is an Expo SDK 57 app
(React Native 0.86, the new architecture, Reanimated 4) with Expo Router. Its catalogue, filter,
sort and sharing logic comes from `@readograph/core` (`packages/core`), the same code the website
runs. The plan is `docs/mobile-app-plan.md`; this file describes what is built.

Status: PR 4 of the plan (the skeleton). The Films tab works; Events, Radar, My films and
Account are placeholders. Nothing has been run on a device yet (see "Device checks").

## Setup

```sh
npm install                # at the repository root; installs the website and the app
cd mobile
npx expo start             # Metro, for a development build or Expo Go
npx expo-doctor            # dependency and config checks
npx expo export --platform ios --output-dir dist/ios          # bundling smoke test
npx expo export --platform android --output-dir dist/android
```

The root `npm run typecheck` includes `tsc -p mobile`, `npm run lint` lints `mobile/`, and
`npm test` runs the app's Vitest suites (`mobile/src/**/*.test.ts`). `ios/` and `android/` are
generated by continuous native generation and are not committed.

The root `package.json` pins `react` and `react-dom` to the version React Native 0.86 needs
(`overrides`): without it npm hoists a newer React for a `*` peer range and the app would load
two copies.

## Running it on a phone

There is no Xcode and no Android SDK on the development Mac, so the app has only been bundled,
not launched. Options, best first:

1. **A development or preview build through EAS** (recommended). EAS profiles arrive with PR 7;
   until then `npx eas-cli@latest build --profile development` needs `expo-dev-client` and an
   `eas.json`, which this PR does not add. A build embeds League Spartan through the `expo-font`
   config plugin and the native modules listed in `mobile/package.json`.
2. **Expo Go, with limits.** Expo's SDK 58 changelog says the store Expo Go moves to SDK 58 only,
   so the store app may already refuse this SDK 57 project. On an Android phone or emulator, or
   the iOS Simulator, an SDK 57 Expo Go can be installed from https://expo.dev/go. On a physical
   iPhone, `npx eas-cli@latest go` builds a private Expo Go for SDK 57 and sends it to TestFlight.
   In Expo Go the embedded fonts are absent (config plugins do not run there), so text falls
   back to the system font.

## Catalogue loading (plan section B)

`mobile/src/catalogue/` implements the loading rules; the pure part is tested under Vitest.

| File           | Role                                                                             |
| -------------- | -------------------------------------------------------------------------------- |
| `loader.ts`    | Fetches `${SITE_ORIGIN}/catalogue.json` and the files it names; rules 2, 4 and 5 |
| `cache.ts`     | One JSON file per generation; reads the newest that passes the checks            |
| `files.ts`     | The cache folder on the device (`expo-file-system`, the app's cache directory)   |
| `store.ts`     | What screens read; rule 1 at launch, rule 3 on returning to the foreground       |
| `provider.tsx` | Wires the store to React and to `AppState`                                       |

- A missing data file is any 404, any `text/html` response and any body that is not JSON.
  Cloudflare Pages serves the site in SPA mode, so a missing `/data/*` file returns 200 with the
  index page. The loader then reads the manifest once more and retries.
- The cache is written as a new file per `generatedAt`, then older files are deleted. An
  interrupted write leaves a file that fails to parse, and the previous one is used.
- `ACCEPTED_SCHEMAS` in `loader.ts` lists the schema versions the app reads. After a breaking
  bump of `DATA_SCHEMA_VERSION`, keep the previous version there for 30 days (`AGENTS.md`).
- A newer schema keeps the cached catalogue on screen with a banner asking for an app update.

## Navigation

- `app/(tabs)/_layout.tsx` renders the five tabs: Films, Events, Radar, My films, Account.
  Each tab folder has its own native stack, so the film detail is pushed inside the Films tab.
- **Tabs fallback.** Native tabs (`expo-router/unstable-native-tabs`) are beta in SDK 57. If the
  device checks find them unreliable, set `USE_NATIVE_TABS = false` in
  `mobile/src/navigation/tabs.ts`; the same route files then render in Expo Router's JavaScript
  `Tabs`, with the same labels and symbols. Nothing else changes.
- Headers are the native stack's, in the masthead red, with the wordmark as the Films title.

## Theme and motion

- `mobile/src/ui/tokens.ts` transcribes the website's dark Picturehouse colours and the
  `--text-1` to `--text-9` scale (13 to 42 points, body 16). Screens use no other colours or
  font sizes. The app is dark only (`userInterfaceStyle: "dark"`); a light set would be a second
  palette in the same file.
- `mobile/src/ui/motion.ts` holds the easing (`Easing.bezier(0.2, 0.8, 0.2, 1)`), the durations
  of the List ⇄ Posters morph and the reduced-motion cross-fade, for PR 5.
- **Fonts.** League Spartan (SIL Open Font License) is embedded from the upstream TTFs
  (`mobile/assets/fonts/SOURCE.txt`). Clash Display is not embedded: Fontshare's licence, as
  recorded in `public/fonts/fontshare/SOURCE.txt`, covers self-hosting on the website and not
  redistributing the font files, and an app binary and this public repository would both
  redistribute them. The wordmark is therefore `mobile/assets/images/wordmark.png`, a 3×
  screenshot of the website's masthead at 390 points (rendered with Playwright from
  `npm run preview` with fixture data). Re-render it the same way if the masthead changes.

## Device checks

Every check below needs a real phone; none has been done. PR 0's spike (plan section "PR 0")
could not run on this machine, so its eight items are folded in here.

1. Core on Hermes: accent folding in search, numeric title sorting and Europe/London dates match
   the Vitest results on iPhone and Android.
2. Native tabs and native stacks on both platforms; otherwise switch to the JavaScript tabs.
3. FlashList scrolls about 1,500 films without dropped frames on a mid-range Android phone;
   the films file downloads in under three seconds on mobile data.
4. An EAS preview build installs on dio's phone.
5. League Spartan renders on both platforms; the wordmark image is sharp in the header.
6. The Filters drawer's eight checks (PR 5).
7. The List ⇄ Posters morph (PR 5).
8. The iOS zoom transition and the Android container transform (PR 5).

PR 4's own device checks are listed in its pull request.
